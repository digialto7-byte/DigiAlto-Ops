# Social batch

## Steps
1. Read the client profile (brand, audience, channels, language, approved facts).
2. `strategist` → `clients/<slug>/deliverables/<date>-social-<weeks>w/plan.md`:
   3–4 content pillars, posting cadence per channel, and a dated calendar.
3. `copywriter` → `posts.md`. For each post:
   ```
   ### <date> · <channel> · <pillar>
   Caption: ...
   Hashtags: ...
   Visual brief: <what the image/video should show, format and ratio>
   Facts used: ...
   ```
   Channel conventions: LinkedIn professional, no emojis and no em dashes for DigiAlto's own
   posts; Instagram short hook first line; Google Business Profile posts factual with a CTA.
4. Optional: `svg-designer` for simple graphic posts (quote cards, icons) when the plan asks.
5. `reviewer` on the folder (max two fix rounds).
6. Report the calendar summary and the folder path. Do not schedule or publish anything.
