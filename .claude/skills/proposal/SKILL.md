# Proposal

## Steps
1. Read `knowledge/clients/<slug>/profile.md`, `clients/<slug>/context.md`,
   `knowledge/agency/services.md`, `knowledge/agency/pricing.md`, `templates/proposal.md`.
2. `strategist` → `clients/<slug>/deliverables/<date>-proposal/plan.md`: the client's need,
   the recommended services (by ID), scope boundaries (what is NOT included), timeline, options.
3. `copywriter` → `proposal.md` in the client's language, following `templates/proposal.md`.
   - Prices only from `pricing.md`. If a service has no approved price, write
     `[PRICE: founder to set]`. Never estimate a price.
   - Payment terms only from `pricing.md` or the client profile.
4. `reviewer` on the folder. Fix rounds as usual (max two).
5. Report the proposal path and the list of `[PRICE]` / `[NEEDS FACT]` items for the founder.

## Never
- Promise results (rankings, revenue, followers, leads).
- Include services DigiAlto does not list.
- Send anything. The founder sends proposals.
