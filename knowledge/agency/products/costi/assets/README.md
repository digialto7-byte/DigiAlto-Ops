# Costì logo assets

Recreated from the 2026-11-13 brand board; approved = founder sign-off pending on these SVGs.

Palette used (exact): Forest #0E4D3A, Coral #FF7A5C, white #FFFFFF (reversed versions and the hat on the app icons). Sage, Off-white and Charcoal are not used in these files.

| File | viewBox | Intended use | Colours |
|---|---|---|---|
| `costi-mark.svg` | 0 0 128 128 | Mark alone on light backgrounds: favicon source, small headers, sign-in page | Forest, Coral |
| `costi-mark-reversed.svg` | 0 0 128 128 | Mark alone on dark or Forest backgrounds | White, Coral |
| `costi-app-icon.svg` | 0 0 512 512 | App icon (rounded square, corner radius 113 = about 22%), home-screen icon, favicon at 48 px and up | Forest, white, Coral |
| `costi-app-icon-maskable.svg` | 0 0 512 512 | PWA maskable icon: full-bleed Forest, mark inside the central 80% safe zone | Forest, white, Coral |
| `costi-wordmark.svg` | -40 -1030 2695 1090 | The word "Costì" alone on light backgrounds, Coral accent over the ì | Forest, Coral |
| `costi-wordmark-reversed.svg` | -40 -1030 2695 1090 | The word "Costì" alone on Forest backgrounds | White, Coral |
| `costi-logo-horizontal.svg` | 0 -6 520 136 | Horizontal logo on light backgrounds: sign-in page, e-mail header, documents | Forest, Coral |
| `costi-logo-horizontal-reversed.svg` | 0 -6 520 136 | Horizontal logo on Forest backgrounds | White, Coral |

Notes
- The wordmark files come from Montserrat Bold outlines (SIL OFL 1.1), supplied by the coordinator. No `<text>` and no fonts are used.
- The mark is hand-drawn: one continuous 16-unit outline (about 14% of the mark width) with three overlapping puffs, straight sides and a rounded base, plus three Coral bars with rounded tops. There is no separate band line.
- In the horizontal logos the mark height is about 1.15x the wordmark cap height and the gap is about 0.25x the mark width. The wordmark paths are copied inline, not referenced.
- All backgrounds are transparent except the two app icons.
- Coral on light backgrounds is for graphics only (contrast rules in `../brand.md`).
- Compare against the board before approval; the mark is a hand-drawn approximation, not a trace.
