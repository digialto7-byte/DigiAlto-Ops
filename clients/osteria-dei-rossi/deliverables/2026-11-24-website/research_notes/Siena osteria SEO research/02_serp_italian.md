## Method notes and limits (read first)

- The search tool uses a US index, not Google.it. It cannot show the real Map Pack, ratings widgets, "People also ask", related searches or autocomplete. No Google.it position is claimed anywhere below.
- The tool returns an ordered list of result titles and URLs plus a short model-written summary. It does NOT return meta descriptions. "Title as shown" below is the title the tool displayed; it is sometimes lowercased or generic (e.g. "Indice Mostra di più", "Per affari"), which means the tool picked up a nav string rather than the real <title>. Treat these as approximate titles.
- WebFetch failed (host not resolvable from this session) for www.frommers.com and www.firenzemadeintuscany.com. I could not read H1s or the inside of any listicle. Per the session message, those hosts would need to be allowed in the session network settings to fetch them. Names inside listicles below come from the tool's summaries of the results, not from reading the pages.
- Labels: OBSERVED = seen in tool output (order and URL). SNIPPET = wording quoted from the tool's summary of a page. INFERRED = my reading across results.
- Order shown is the order the tool returned URLs. It is not a Google ranking.
- About 25 search calls were made, so each query was run once, in standard mode. No query was repeated.

## 1. Query-by-query results (top 8-10, domain, title as shown, page type, URL)

### Takeaway
Across all 22 queries plus 2 extras, I observed zero restaurant-owned domains in the top results. Every result was an aggregator (Michelin Guide, OpenTable, Wanderlog, Sluurpy, Foursquare, TripAdvisor, Restaurant Guru, Swipein, piatti.menu), a tourism portal (italia.it, visittuscany.com), a travel listicle or blog (discovertuscany.com, travel365.it, doeatbetterexperience.com, firenzemadeintuscany.com, thetourguy.com), or a guide/press site (gamberorosso.it, scattidigusto.it, lanazione.it, dissapore.com).
